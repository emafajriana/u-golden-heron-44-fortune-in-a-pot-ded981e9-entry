A make.fun entry for **Fortune in a Pot**: one kind, funny fortune for the
houseplant on the windowsill, in a single line of at most 120 characters.

> This week the sun will linger on your windowsill, and your keeper will
> take full credit for your new leaf.

`main.py` (Python 3.13, standard library only) writes the fortune to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output`),
validating the 1–120 character gate first and verifying the written bytes
on read-back.

Run it:

```sh
python3 main.py
```
